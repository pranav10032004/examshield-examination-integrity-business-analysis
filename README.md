# ExamShield - Examination Integrity & Centre Operations Analytics

## Portfolio Case Study
Independent Business Analyst / BI case study.

### Problem
Public examinations operate across secure logistics, exam centres, candidate identity, surveillance, incident handling and recovery. The public evidence around NEET-UG 2026 and SSC Selection Post Phase XIII shows why a unified operational view can be valuable.

### What is included
- `Research/01_ExamShield_Research_Report.pdf` - public-source research and evidence timeline
- `Research/02_ExamShield_BI_Report_and_Data_Description.pdf` - dashboard and dataset specification
- `Research/03_ExamShield_Business_Solution_and_Future_State.pdf` - BA solution, stakeholders, requirements and future state
- `Research/04_ExamShield_Interview_Cheat_Sheet.pdf` - interview preparation
- `Data/ExamShield_Public_Evidence_Register.csv` - source-backed evidence events
- `Data/ExamShield_Source_Register.csv` - source traceability
- `Data/ExamShield_Illustrative_Centre_Operations.csv` - synthetic demonstration data
- `Data/ExamShield_Project_Data.xlsx` - Excel workbook with evidence, sources, operations model and data dictionary
- `SQL/ExamShield_Analysis.sql` - PostgreSQL queries
- `Dashboard/ExamShield_BI_Report_Mockup.png` - static Power BI-style report mockup

### Important data note
The public evidence register is source-backed. The centre-operations dataset is synthetic and exists only to demonstrate analytical design. It must not be described as observed centre-level risk.

### Core BA storyline
Current state -> fragmented event/control visibility -> need for exception management -> future state control tower.

### Suggested LinkedIn asset
Use the dashboard image first, then describe the research, SQL, KPI design, data governance and future-state solution.
